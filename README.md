# Старинная Коллекция — разбитая версия сайта

## Структура
- `index.html` — разметка сайта
- `css/style.css` — стили
- `js/catalog.js` — каталог товаров
- `js/config.js` — контактные настройки
- `js/app.js` — основная логика
- `js/pages.js` — страницы товара, корзина, оформление и личный кабинет
- `js/animations.js` — анимации

## Публикация
Загрузите **все содержимое папки** `antique-shop` на статический хостинг, сохранив структуру папок. Главный файл — `index.html`.
Можно использовать GitHub Pages, Netlify или Cloudflare Pages. Для простого статического сайта сборка не нужна.

## Важно перед реальным запуском
Это разделение не добавляет серверную часть. Корзина, отзывы, заказы и личный кабинет могут работать только на стороне браузера, если код не подключён к серверу. Заказы не будут автоматически приходить владельцу сайта, а данные пользователей не будут общей базой. Для настоящих заказов нужны backend/API и безопасное хранение данных.
Проверьте телефон, email, ссылки и карточки товаров перед публикацией. Внешние изображения, Google Fonts и Font Awesome требуют подключения к интернету.
