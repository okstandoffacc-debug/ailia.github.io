# Старинная Коллекция — личный кабинет владельца, фото и заказы

Сайт размещается на GitHub Pages, данные хранятся в Supabase. Отдельная страница «Админ-панель» удалена: владелец управляет объявлениями из своего личного кабинета.

## Что добавлено
- Владелец с ролью `admin` видит в личном кабинете блок «Управление магазином». Обычные аккаунты его не видят и не могут редактировать каталог благодаря RLS.
- Фото можно выбирать с компьютера. Файлы загружаются в Supabase Storage (`product-photos`), первая фотография становится обложкой, весь список ссылок сохраняется в `photos`. Максимум 8 МБ на фото.
- В заказе можно купить только один экземпляр каждого антикварного предмета. Оформление вызывает транзакционную функцию `create_shop_order`, которая проверяет наличие, создаёт заказ и снимает товар с витрины, чтобы другой покупатель не мог его заказать.
- Покупатель видит свои заказы в личном кабинете. Владелец меняет статусы и вносит трек-номер/комментарий в разделе «Заказы и доставка».
- Статусы: «Заказ оформлен», «Отправлен», «Прибыл на склад / сортировочный центр», «Готов к получению», «Получен покупателем», «Отменён». Если заказ отменён, владелец может вернуть товар в наличие кнопкой «Вернуть в наличие».

## Обновление существующего проекта
1. **Сначала сохраните ваш действующий `js/config.js` отдельно.** В нём уже должны быть ваш Project URL и Publishable key. Не затирайте этот файл версией из архива, в которой могут быть заглушки.
2. В Supabase откройте **SQL Editor → New query** и выполните обновлённый `supabase-schema.sql` целиком. Он добавляет `available`, `orders`, политики RLS, bucket для фото и функцию безопасного оформления заказа.
3. Загрузите остальные обновлённые файлы на GitHub, сохранив структуру папок. `js/config.js` оставьте ваш рабочий. Удалите старые `admin.html` и `js/admin.js`, если они остались в репозитории.
4. Проверьте, что ваш профиль в `public.profiles` имеет `role = 'admin'`. Только владелец должен иметь эту роль.
5. Войдите под владельцем, откройте личный кабинет. Появится блок «Управление магазином».
6. Если в `products` ещё нет товаров, используйте импорт каталога из предыдущей версии до удаления старой админ-страницы, либо попросите перенести каталог отдельно. Не запускайте повторный импорт вслепую: он может создать лишние записи.
7. В Supabase → **Storage** проверьте bucket `product-photos`. SQL создаёт публичное чтение фотографий и разрешает загрузку/изменение/удаление только администраторам.

## Отслеживание доставки — важно
Сейчас статусы в личном кабинете **обновляет владелец вручную**. Настоящее автоматическое отслеживание требует API/договора и учётных данных выбранного перевозчика; публичный сайт не должен содержать секретные API-ключи. Список статусов сделан по типичным этапам перевозчиков, а не обещает синхронизацию с их системами.

Справка по статусам:
- Почта России: [официальное описание отслеживания](https://info.pochta.ru/support/popular-questions/tracking/products-location) — присвоен трек-номер, принято в отделении, сортировка, прибыло в место вручения, получено адресатом.
- СДЭК: [официальное отслеживание](https://ff.cdek.ru/tracking) — создан, принят, в пути/сортировочном центре, готов к выдаче, вручён.
- Яндекс Доставка: [официальные статусы](https://yandex.ru/support/delivery-profile/ru/other-day/check-status) — принят, в пути, ждёт получения, доставлен.
- Яндекс трекинг: [статусы для получателя](https://dostavka.yandex.ru/ndd/tracking).

Ozon/Яндекс Маркет могут быть способом доставки только при наличии у продавца соответствующего доступа/договора. Эта сборка не подключает API Ozon, Почты России, Яндекс Доставки или СДЭК и не получает статусы автоматически.

## Проверка перед использованием
- Обычный пользователь не видит управления магазином.
- Владелец может загрузить фото и создать/редактировать/удалить товар.
- После заказа товар исчезает из публичного каталога и отображается в заказе покупателя.
- Два одновременных заказа одного товара: только один должен пройти; второму покажется ошибка о том, что товар уже заказан.
- Проверить реальное оформление заказа только на тестовом товаре.
