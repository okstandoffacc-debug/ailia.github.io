# Удаление фона фотографий в кабинете владельца

В форме добавления/редактирования товара выберите одно или несколько фото и нажмите **«Убрать фон → белый»**. Обработка выполняется в браузере через `@imgly/background-removal`; секретный API-ключ не нужен и фотографии не отправляются на сторонний сервер для сегментации. Затем нажмите **«Сохранить объявление»**, чтобы загрузить результат в Supabase Storage.

При первом запуске браузер скачает библиотеку и модель ИИ (примерно десятки мегабайт), поэтому требуется интернет и нужно подождать. После обработки обязательно проверьте предпросмотр: у прозрачных, стеклянных и очень тонких предметов ИИ может ошибаться. Кнопка «Сбросить обработку» возвращает исходные выбранные фотографии.
